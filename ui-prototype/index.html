Recovery — if a flash ever goes wrong

J4004 header + CH347 programmer (native 3.3 V) + flashrom -p ch341a_spi. Full wiring table is built into the native UI. ⚠ Some CH341A units output 5 V and can damage the chip.

Diagnostics & Stress Tests

Quick check (~2 min)
Sensors sweep · NVMe SMART + short read · memory quick pattern · display EDID · network · GPU/CU detection
CPU stress — stress-ng, 10 min
Watch temps live on the Dashboard graph. Throttling events are logged — this is how you learn if your board is stable at 8 cores.
GPU stress + CU stability
The honest way to test a 32/36/40-CU unlock: not every board is stable at 40. BC-250-X reports — it never forces an unlock.
Memory test — Memtest86+
Reboots into the EFI memory tester (open source). Best run overnight for a new board.
NVMe benchmark — fio
Expect ~1 GB/s ceiling: BC-250's M.2 is PCIe 2.0 x2. A faster drive will not beat the link.
Every run saves a timestamped report (.txt + .json) to USB.
